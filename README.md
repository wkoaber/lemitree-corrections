# LemiTree corrections

LemiTree (www.lemitree.com) is a nonprofit library of proven actions for a flourishing life. Every action shows the research behind it, and we would rather hear about a mistake than keep it.

**Spotted something wrong or missing?** Open the action on the website, tap **Suggest a correction**, and the form opens here with the action already filled in. You can also start one directly: [Suggest a correction](../../issues/new?template=correction.yml).

## What happens next

1. A person reads every suggestion, usually within a week.
2. Labels show where it stands: `to triage`, `accepted`, `needs source`, `declined`.
3. Accepted corrections go into the next update of the library, and we close the issue with a short note on what changed.

## Please

- Name the action and, for evidence, the study (a DOI or PubMed ID helps most).
- Keep it public-safe: no health information about yourself or anyone else.

This repository holds suggestions only. The library itself and the tools that build it are maintained by Stichting LemiTree, Maastricht, the Netherlands. Contact: socials@lemitree.com
